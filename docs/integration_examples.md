# Integration Examples

This guide shows where the gem fits in a real Rails app and what argument types its public methods expect.

## Files You Usually Touch

Typical host app integration uses these files:

- `Gemfile`: add `gem "open_router_usage_tracker", "~> 2.0"`.
- `db/migrate/*`: generated by the gem install generators.
- `app/models/user.rb`: include `OpenRouterUsageTracker::Trackable`.
- `config/initializers/open_router_usage_tracker.rb`: configure pricing, redaction, and instrumentation.
- `app/services/*` or `app/jobs/*`: call the LLM provider and log the response.
- Controllers or policy objects: query usage summaries before allowing more requests.

## Initializer Example

Create `config/initializers/open_router_usage_tracker.rb` in the host Rails app:

```ruby
# config/initializers/open_router_usage_tracker.rb
OpenRouterUsageTracker.configure do |config|
  config.pricing = {
    "open_ai" => {
      "gpt-4.1-2025-04-14" => {
        "input_cost_per_million" => 2.00,
        "output_cost_per_million" => 8.00,
        "cache_read_input_cost_per_million" => 0.50,
        "cache_write_input_cost_per_million" => 2.50,
        "reasoning_output_cost_per_million" => 8.00,
        "currency" => "USD"
      }
    }
  }

  config.raw_response_redactor = lambda do |response|
    response.deep_dup.tap do |redacted|
      redacted.delete("api_key")
      redacted["metadata"]&.delete("email")
    end
  end
end

ActiveSupport::Notifications.subscribe("log.open_router_usage_tracker") do |_name, _started, _finished, _id, payload|
  Rails.logger.info(
    event: "llm_usage_logged",
    provider: payload[:provider],
    model: payload[:model],
    request_id: payload[:request_id],
    user_type: payload[:user_type],
    user_id: payload[:user_id]
  )
end
```

The gem does not fetch live pricing. Treat the pricing hash as app-owned billing configuration.

## Model Example

```ruby
# app/models/user.rb
class User < ApplicationRecord
  include OpenRouterUsageTracker::Trackable

  # Choose this only if your product should delete usage history with the user.
  # has_many :usage_logs, as: :user, class_name: "OpenRouterUsageTracker::UsageLog", dependent: :destroy
  # has_many :daily_summaries, as: :user, class_name: "OpenRouterUsageTracker::DailySummary", dependent: :destroy
end
```

By default, the gem does not destroy usage data when a user is destroyed.

## Service Object Example

Use the gem after a successful provider call. The response must be a parsed provider response hash, not a raw JSON string.

```ruby
# app/services/answer_question.rb
class AnswerQuestion
  def initialize(user:, provider_client:)
    @user = user
    @provider_client = provider_client
  end

  def call(prompt)
    response = provider_client.responses.create(
      model: "gpt-4.1-2025-04-14",
      input: prompt
    )

    response_hash = response.respond_to?(:to_h) ? response.to_h : response

    usage_log = OpenRouterUsageTracker.log(
      response: response_hash,
      user: user,
      provider: "open_ai",
      occurred_at: Time.current,
      on_duplicate: :return_existing
    )

    {
      answer: response_hash.dig("output", 0, "content", 0, "text"),
      usage_log: usage_log
    }
  end

  private

  attr_reader :user, :provider_client
end
```

If a client returns JSON text, parse it first:

```ruby
response_hash = JSON.parse(response_body)
OpenRouterUsageTracker.log(response: response_hash, user: current_user, provider: "open_router")
```

## Controller Rate-Limit Example

```ruby
# app/controllers/messages_controller.rb
class MessagesController < ApplicationController
  before_action :enforce_llm_limit

  def create
    result = AnswerQuestion.new(user: current_user, provider_client: openai_client).call(params[:prompt])
    render json: { answer: result[:answer] }
  end

  private

  def enforce_llm_limit
    summary = current_user.daily_usage_summary_for(
      day: Time.zone.today,
      provider: "open_ai",
      model: "gpt-4.1-2025-04-14"
    )

    return if summary.nil? || summary.total_tokens < 100_000

    render json: { error: "Daily token limit exceeded" }, status: :too_many_requests
  end
end
```

## Background Job Example

Logging from a job works the same way. Pass a persisted user or account record.

```ruby
# app/jobs/summarize_document_job.rb
class SummarizeDocumentJob < ApplicationJob
  queue_as :default

  def perform(user_id, document_id)
    user = User.find(user_id)
    document = Document.find(document_id)

    response = AnthropicClient.new.messages.create(
      model: "claude-opus-4-1-20250805",
      messages: [{ role: "user", content: document.body }]
    )

    OpenRouterUsageTracker.log(
      response: response.to_h,
      user: user,
      provider: "anthropic",
      store_raw_response: false
    )
  end
end
```

## Public API Argument Types

### `OpenRouterUsageTracker.configure`

```ruby
OpenRouterUsageTracker.configure do |config|
  config.pricing = {}
  config.raw_response_redactor = ->(response) { response }
end
```

- `config.pricing`: `Hash`.
  - Provider keys: `String` or `Symbol`.
  - Model keys: `String` or `Symbol`.
  - Price keys: `String` or `Symbol`.
  - Price values: numeric values or strings accepted by `BigDecimal(value.to_s)`.
- `config.raw_response_redactor`: callable object accepting one response hash and returning a JSON-serializable redacted response.

### `OpenRouterUsageTracker.log`

```ruby
OpenRouterUsageTracker.log(
  response: response_hash,
  user: current_user,
  provider: "open_ai",
  store_raw_response: true,
  occurred_at: Time.current,
  on_duplicate: :raise
)
```

Accepted arguments:

- `response`: provider response hash with `String` or `Symbol` keys. It must include provider-required model, request id, and usage fields.
- `user`: persisted ActiveRecord object. Any model can work if it includes `OpenRouterUsageTracker::Trackable`, but the log itself only needs a polymorphic ActiveRecord user-like record.
- `provider`: `String`. Supported values are `"open_router"`, `"open_ai"`, `"google"`, `"anthropic"`, and `"x_ai"`.
- `store_raw_response`: boolean. Defaults to `true`.
- `occurred_at`: `Time`, `ActiveSupport::TimeWithZone`, `DateTime`, or `Date`. Defaults to `Time.current`; values are stored in `occurred_at` and converted to a summary `day` with `to_date`.
- `on_duplicate`: `Symbol` or `String` responding to `to_sym`. Supported values are `:raise`, `:return_existing`, and `:ignore`.

Return value:

- `OpenRouterUsageTracker::UsageLog` for a newly logged request.
- Existing `UsageLog` when `on_duplicate: :return_existing`.
- `nil` when `on_duplicate: :ignore` and the request already exists.

Errors:

- `ArgumentError` for unsupported providers or duplicate policies.
- `OpenRouterUsageTracker::ParseError` for missing or invalid provider response fields.
- ActiveRecord exceptions for validation or persistence failures.

### `Trackable` Query Helpers

Available on models that include `OpenRouterUsageTracker::Trackable`:

```ruby
user.daily_usage_summary_for(day:, provider:, model:)
user.total_cost_in_range(range, provider:, model: nil)
user.total_tokens_in_range(range, provider:, model: nil)
user.request_count_in_range(range, provider:, model: nil)
user.usage_totals_in_range(range, provider:, model: nil)
```

Accepted arguments:

- `day`: `Date` recommended. Use `Time.zone.today` for timezone-aware daily limits.
- `range`: `Range<Date>` or `Range<Time>`.
  - `Date` ranges expand to full days for request counts.
  - `Time` ranges are exact for request counts.
  - Summary-backed helpers query `DailySummary.day`, so use `Date` ranges there.
- `provider`: `String`, matching a supported provider.
- `model`: optional `String`; omit to aggregate all models for the provider.

Return values:

- `daily_usage_summary_for`: `OpenRouterUsageTracker::DailySummary` or `nil`.
- `total_cost_in_range`: decimal sum from summaries.
- `total_tokens_in_range`: integer token sum from summaries.
- `request_count_in_range`: integer count from usage logs.
- `usage_totals_in_range`: hash with `:input_tokens`, `:output_tokens`, `:total_tokens`, cache/reasoning counters, and `:cost_amount`.

### Maintenance Services

```ruby
OpenRouterUsageTracker::Maintenance::DailySummaryRebuilder.call
OpenRouterUsageTracker::Maintenance::DailySummaryRebuilder.call(scope: OpenRouterUsageTracker::UsageLog.where(provider: "open_ai"))
OpenRouterUsageTracker::Maintenance::RawResponsePruner.call(before: 90.days.ago)
```

- `DailySummaryRebuilder.call`: full rebuild; deletes all summaries and recreates them from all usage logs.
- `DailySummaryRebuilder.call(scope:)`: scoped rebuild; scope must be an `ActiveRecord::Relation` of `UsageLog` rows and should contain complete summary buckets.
- `RawResponsePruner.call(before:)`: accepts a `Time`, `ActiveSupport::TimeWithZone`, `DateTime`, or `Date`; clears raw responses for logs with `occurred_at < before`.

Return values are integer counts.
